"In src/screens/TodayScreen.tsx, find the pillar table. Add a column called 'Δ since prior' that reads from analysis.driftProfile (already returned by /analysis). Use mint for positive deltas, coral for negative, em-dash if no prior assessment exists. Pillar order stays sorted by gap desc. Why this is better: you named the file, the prop, the data source, the visual treatment, AND the failure mode. AI can't get this wrong.

When AI gets stuck — the debugging compass

Hit a bug? Match the symptom to the file:

score is wrong Look in shared/engines.ts. Run npx vitest run tests/engines.test.ts — the failing test will name the formula.
drift is wrong Look in api/assessments/[id]/analysis.ts — the SQL query that finds the prior assessment. Operator + entity + completed status filter.
UI shows stale data Edge cache. Check vercel.json and api/_lib/cache.ts. Force-refresh skips the cache.
upload fails silently SUPABASE_SERVICE_ROLE_KEY missing in Vercel env. The endpoint throws a clear error.
App.tsx merge conflicts Most edits should NOT touch App.tsx. If your AI is editing it, ask "should this go in a screen file under src/screens/ instead?"
