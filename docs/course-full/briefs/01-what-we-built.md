# Module 1 brief — What we built

## Teaching arc
- **Metaphor:** A scientific instrument (thermometer / pH meter), not a consulting deck
- **Opening hook:** Consultants take 90 days, hand-tally scores by feel, deliver a deck. ERM Navigator makes the same number reproducible in minutes.
- **Key insight:** The product's moat is a property (reproducibility), not a feature
