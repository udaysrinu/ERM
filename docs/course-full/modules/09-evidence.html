Evidence — the audit-grade attachment story.

A score with no document behind it is hearsay. Real customers need real files in real storage with real access control.

A bank's safe-deposit box, not a public locker

The metaphor matters. We could have stored evidence in any old bucket and called it a day. We didn't. Every uploaded file lives in a private bucket, never publicly listable, accessible only via short-lived signed links our function issues per-request after verifying ownership.

The 5 properties that make storage audit-grade

private bucket No public listing. No public URL. The only way in is a signed link our function issues.
10 MB / file cap Server-side rejection of larger uploads — saves bandwidth, fits ERM evidence shape (PDFs, Excel, screenshots).
MIME allowlist PDF, XLSX, DOCX, common images, plain text. Bucket itself rejects anything else, regardless of file extension.
5-min signed URLs Download links expire in 300 seconds. Even if a link leaks via screenshare, it's stale by the time anyone tries.
deterministic key {assessmentId}/{questionId}-{filename}. One slot per (assessment, question). Re-uploads overwrite the slot.

Why this dance

The service-role key can do anything. If it ended up in a browser bundle, the whole evidence locker becomes public. So the function holds the key, mints a 60-second-window upload URL, and hands ONLY that URL to the browser. The browser uploads directly to Storage — fast, no proxying through the function. Same pattern for downloads, with a 5-minute window.

Two columns, two purposes

SCHEMA · responses table 
CREATE TABLE responses (
  id serial PRIMARY KEY,
  "assessmentId" text,
  "questionId" int,
  score int,
  note text,
  "evidenceName" text DEFAULT '',
  "evidencePath" text DEFAULT '',
  "answeredAt" timestamptz
);
PLAIN ENGLISH

evidenceName — the human-readable filename. Always captured if the operator references a file, EVEN IF the upload itself fails.

evidencePath — the Storage object key. Only set if the upload actually succeeded.

Why two? Audit trail. If an operator says "I attached control-test.pdf" but the upload errored, the audit trail still shows the reference — just without a downloadable file. The Evidence library renders these rows as "name only" in muted ink.

Honesty principle: the UI never fabricates a download where one doesn't exist. Better to show "name only" than a broken link.
