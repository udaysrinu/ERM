A codebase isn't done; it's handed off. This is the file map, the debugging compass, and the AI-prompting playbook for whoever sits in this chair next.

A subway map, not a tour

You don't need to memorize every station. You need to know which line goes where, so when something breaks, you can find the right train fast. This module is that map.

AI prompting — what works on this codebase

EXAMPLES 
// ✅ Concrete, anchored, testable
"In shared/engines.ts:165, generateRoadmap sorts by
 uplift / (cost × duration). Add a tie-breaker on
 pillarWeight desc, and update the test in
 shared/__tests__/engines.test.ts."

// ❌ Vague, no anchor
"Make the roadmap smarter."

// ✅ Names the invariant to preserve
"Add answeredAt rendering to Provenance.
 The signature hash MUST NOT change — it
 excludes timestamps by design (Module 5)."

// ❌ Doesn't name the invariant — risks regression
"Show timestamps in Provenance."
PLAIN ENGLISH

Anchor with a path + line. "shared/engines.ts:165" is a contract — the model can't guess the wrong file.

Name the invariant. The hash is sacred. Caching depends on it. Drift comparisons depend on it. Tell the model.

Cite the test file. Prefer "update X.test.ts" over "make sure tests still pass." Specific test files keep the model focused.

Adversarial review beats self-review. The Codex P1 catch on App.tsx (the batched setter race) shipped because a second model read the diff cold. Use Codex / a second pass before merging anything in shared/ or api/.

The closing principle

The thing that makes this codebase defensible isn't any one feature. It's that the score is a pure function, the inputs are hashed, the receipts are printable, and every UI surface refuses to fabricate. Keep those four properties true and the patent moat stays a moat. Break any one of them and the product becomes another dashboard.

🧭
If you remember one thing

Same answers + same catalog → same hash → same numbers. That sentence is the entire product. Everything else — the charts, the PDF, the evidence locker, the cache — is in service of making that sentence visible to a non-technical auditor.
